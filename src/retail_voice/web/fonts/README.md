# Fonts

Both are variable fonts under the SIL Open Font License 1.1, downloaded once from
the Google Fonts repository and committed. The page loads them from `/app/fonts/`,
so a render never touches the network.

| File | Family | Used for | Licence |
|---|---|---|---|
| `InstrumentSans.ttf` | Instrument Sans, weights 400 to 700 | everything | `OFL-InstrumentSans.txt` |
| `JetBrainsMono.ttf` | JetBrains Mono, weights 100 to 800 | numbers only | `OFL-JetBrainsMono.txt` |

Instrument Sans follows the Akamai demo template. JetBrains Mono is used for
numeric readouts so changing values remain aligned.
